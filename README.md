# Lordam Data Engine

Plataforma de engenharia de dados (ETL/ELT, limpeza, cruzamento, IA em linguagem natural, ML, integração com Power BI) para substituir processos manuais de tratamento de dados em Excel/Power Query.

**Status atual:** fase de planejamento arquitetural. Nenhum código de produto foi implementado ainda.

Veja o plano de arquitetura completo — bounded contexts, estrutura de diretórios, stack, modelo de dados, riscos, decisões técnicas e ordem de desenvolvimento — em [`docs/ARCHITECTURE.md`](docs/ARCHITECTURE.md).
